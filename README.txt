ABONIKA MODERN WEBSITE

Files:
- index.html (main website)

Deploy:
1. Extract this ZIP on your PC.
2. Open your GitHub repository: https://github.com/atikrhm/abonika
3. Click Add file > Upload files.
4. Upload index.html (replace the old index.html if asked).
5. Click Commit changes.
6. Wait for Cloudflare Pages to deploy, then open https://abonika.pages.dev

Important:
The built-in product manager currently saves changes only in the browser/device where you use it. It does NOT sync product changes to every customer's browser. For shared online product management, connect Firebase/Firestore and secure admin login before using it as a live store.
To enable WhatsApp ordering, edit index.html and replace const phone="" with your WhatsApp number including country code, without + or spaces (Bangladesh example format: 8801XXXXXXXXX).
